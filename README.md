# Pink Aesthetic Web App ✨

A stunning, interactive, minimalist web application celebrating warm shades of pink, built using clean HTML, modern CSS variables, fluid keyframe animations, glassmorphic layout, and interactive Vanilla JavaScript.

## Features
- 🌸 **Fluid Glassmorphism:** A modern, premium UI card floating over moving organic gradient ambient glowing orbs.
- 🎨 **Dynamic Color Space:** Click the **Change Shade** button to cycle randomly through curated, warm, and beautiful pink colors (Cotton Candy, Cherry Blossom, Baby Pink, Rose Gold, Hot Pink, and more!).
- 📋 **Seamless Hex Clipboard Copying:** Click the **Copy Hex** button to instantly copy the currently displayed pink hex code to your clipboard with immediate micro-interaction feedback.
- 📱 **Fully Responsive Layout:** Optimized for all screen sizes, from high-resolution desktop displays to mobile screens.
- ⚡ **Ultra Lightweight:** Powered by Vanilla Web Standards and served using **Vite** for a blazing-fast local developer experience.

## Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) installed on your machine.

### Installation & Run

1. Open a terminal inside the project directory or set this folder as your active workspace.
2. Install dependencies (if not already done):
   ```bash
   npm install
   ```
3. Launch the development server:
   ```bash
   npm run dev
   ```
4. Open the displayed local URL (typically `http://localhost:5173`) in your browser to experience the application!
